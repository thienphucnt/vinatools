Integration Code Snippets

Copy and paste code directly into your local scripts to query our API endpoints.

curl -X GET "https://vinaearn-ai.vercel.app/api/company?tax_code=0100109106"
fetch("https://vinaearn-ai.vercel.app/api/company?tax_code=0100109106")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error("Error:", error));
import requests

url = "https://vinaearn-ai.vercel.app/api/company"
params = {"tax_code": "0100109106"}

response = requests.get(url, params=params)
if response.status_code == 200:
    company_data = response.json()
    print(company_data)
else:
    print(f"Error: {response.status_code}")

API Reference Docs

All parameters, authentication standards, and schema descriptions.

GET /api/company

Look up official company parameters by their 10-digit tax code (Mã số thuế).

Parameter Type Requirement Description
tax_code STRING Required The 10-digit business registration number (Mã số thuế) representing a business in Vietnam. e.g. 0100109106.

GET /api/search

Query businesses by keyword matching official registered business names.

Parameter Type Requirement Description
q STRING Required The company keyword query search term. e.g. cong ty xay dung.
province STRING Optional Filter results by province or city. e.g. hanoi, hcm, danang, binhduong.
status STRING Optional Filter results by operational status. Supported: active, inactive, all (default: active).
page INTEGER Optional Pagination index for results. Starts at 1.
limit INTEGER Optional Results limits. Maximum: 20 (default: 10).
